# Security policy

Report a vulnerability in KA-Reader through this repository's private vulnerability reporting: on the repository's page, open the *Security* tab and choose *Report a vulnerability*. It is the one place for a report. There is no e-mail address for reports, and a vulnerability reported in a public issue can be read by anyone.

Issues and questions are welcome and are read when there is time. There is no response time, no commitment to fix, and no promise that a fix arrives. Security reports have a private channel and are read on the same terms.
