# Changelog — `ka-reader`

Each entry records a change to what a user of a fresh clone installs, runs, types or reads in KA-Reader. It names the project the change was made under and cites the commits that made it. The format follows [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Upgrading

- **ka-reader** — The product is renamed from Nozoki to KA-Reader. The app, its crates (`ka-reader-core`, `ka-reader-bridge`) and its Swift package (`ka-reader-mac`) carry the new name, so a clone made before the rename builds and runs under the new names. (`c915d52be`, `4b98c175e`)
- **ka-reader** — KA-Reader needs macOS 26 or later, and its bridge is built for that floor. (`f0f1e5fcf`)

- **ka-reader** — KA-Reader has a version, `0.1.0`, stated once in the root `Cargo.toml`. It then packs the ad-hoc-signed app as `KA-Reader-<version>.dmg` with a `SHA256SUMS` file beside it, checks the image against that file, and only then creates a draft GitHub Release that holds both. A tag that already has a Release is refused, and that Release is left as it was. `checks/gate.sh` now checks the workflow's shape and runs the suites of `checks/release-version.sh`, `checks/release-pack.sh`, `checks/release-sums.sh` and `checks/release-absent.sh`. ### Changed

- **ka-reader** — The README opens with what KA-Reader does, the disk-image install route, choosing a folder in the Open panel and what the app will and will not touch. It states the support terms and other standing promises below that opening. `checks/readme.sh` checks the six required README wordings, the support wording in `SECURITY.md` and repository-only image sources; `checks/gate.sh` runs it and its suite as fatal steps. (`d274f373c`, `1ee6ba1b6`)
- **ka-reader** — The launch steps refuse to run off a virtual machine. (`13e8d42e9`)
- **ka-reader** — The bridge's C-string calls build under both Swift 6.3 and 6.4. (`24be58134`)
- **ka-reader** — A Markdown file you open, one named `.md` or `.markdown`, no longer shows its text. The reading panel says *KA-Reader stopped while reading this file and can't tell why.* in its place. When an open Markdown file changes on disk, the window shows neither that change nor the changes to the file tree that arrive with it. (`89275360e`, `681135152`)
- **ka-reader** — Each entry in `THIRD_PARTY_NOTICES.md` now gives every copyright line its component's licence files state, for every crate, every library a crate compiles, and the Lucide icons, and says so where a package holds no licence file or its licence files state no copyright line. `checks/notices.sh` now also reads every licence file of every crate it names, and exits 1 when a copyright line in one is missing from that crate's entry, naming the crate, the file and the line. It also exits 1, saying nothing was checked, when it cannot find or read a crate's licence files. Its name check, its pass line and its other messages are as they were. (`695f023d8`, `6580e2287`, `d42ab77f9`, `aacc44c42`, `77e8688ab`, `9da791d2b`, `c977941a0`, `4ab28e50f`)
- **ka-reader** — KA-Reader's version moves from `0.0.0` to `0.1.0`. The root `Cargo.toml` states it, `Cargo.lock` gives it to both crates, and the app's `Info.plist` gives it as `CFBundleShortVersionString`, so a release tag must now be `v0.1.0` and the release's disk image is named `KA-Reader-0.1.0.dmg`. (`3f3a08860`)
- **ka-reader** — The built app shows the drawn eye as its icon, in the Dock, the application switcher and Finder, in place of the plain blue square it carried before. `ka-reader-mac/assemble.sh` renders the icon from `docs/design/app_icon.svg` on every build with `sips` and `iconutil`, which come with macOS, and stops before the build when the drawing is missing or does not render. `ka-reader-mac/icon.icns` is gone. `checks/bundle.sh` now refuses a bundle that still carries the old icon before it launches anything, and names each file that does. `checks/app-icon.sh` holds the built icon to the drawing's sizes and colours, and `checks/gate.sh` runs it, its suite and the build script's suite. (`338288d98`, `47e3e68ac`, `e9e2bed50`, `2821e1061`, `e96a78723`)

### Removed

### Fixed

- **ka-reader** — Re-entering a folder through a spelling that differs only in case stays inside the opened folder, and that re-entry is limited to case-only spellings. (`368c8a4ec`, `df53a4f46`)
- **ka-reader** — Two processes writing the shared log keep it within its bound. (`af416967f`)
- **ka-reader** — When you click two files in quick succession, KA-Reader ends on the second, whichever read finishes first. The panel shows it and follows it on disk, and your place in it is kept. (`068785415`, `0203fbd5e`, `d2874d693`, `5e5f39c2e`, `3bbc07d30`)
- **ka-reader** — On a rendered Markdown page, a link to a folder inside the opened folder now shows where it points and does nothing, as a link that leads anywhere but a file does. Before, it was a control that opened nothing. Code on the page, in a block or inline in a line of text, now sits on a background of its own that sets it off from the prose, with padding, rounded corners and no border. (`374faf7afe`, `9c53f14406`, `bb6534ce84`, `27e2521254`, `b6a3216fc0`)
- **ka-reader** — On a rendered Markdown page, the box shown where an image would be now sits on a background of its own that sets it off from the page, with rounded corners, its thin border and more room around its text. Before, it shared the page's background and had square corners. (`7f56d3c97`)
- **ka-reader** — When KA-Reader can't read a folder's Git status, the Git view no longer says it will show the status later. It says what KA-Reader found when you opened the folder, and that starting KA-Reader again reads the status again. (`88c11734e`)
- **ka-reader** — When KA-Reader stops and can't tell why before it has found out whether the opened folder is a repository, the Git view now says so and no longer calls the folder a repository. Before, every such stop said KA-Reader had stopped while reading this repository's Git status, even for a folder that isn't one. A stop after a repository was found keeps that sentence. (`82903be25`)
